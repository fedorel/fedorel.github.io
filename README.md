# Terminal-Style Link-in-Bio Website

Личный сайт-визитка, стилизованный под терминал Linux и консоль разработчика. Проект создан для удобного размещения ключевых ссылок, контактов и портфолио в одном месте.

Живой сайт доступен по адресу: [https://fedorel.github.io](https://fedorel.github.io)

---

## Структура репозитория

* index.html — разметка страницы.
* style.css — стили оформления.
